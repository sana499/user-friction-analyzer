**Author:**Sana P
**MUID:** sana-1@mulearn

## 📖 Project Overview
This project is a machine learning web application built for Task 9. It predicts the likelihood of a customer abandoning a service (churning) based on behavioral and financial metrics. By analyzing user friction points—such as support calls, payment delays, and contract lengths—the model calculates a precise churn probability to help businesses proactively retain their customers.

## ✨ Features
* **Interactive Web Interface:** A clean UI built with Streamlit that allows users to input customer metrics in real-time.
* **Behavioral Analysis:** Evaluates key decision-making factors like Tenure, Support Calls, and Total Spend.
* **Machine Learning Engine:** Powered by a lightweight Random Forest Classifier trained on historical customer data.
* **Instant Risk Assessment:** Outputs a clear probability percentage alongside an actionable risk alert.

## 🛠️ Tech Stack
* **Language:** Python
* **Data Processing:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn, Joblib
* **Frontend & Deployment:** Streamlit, Streamlit Community Cloud
